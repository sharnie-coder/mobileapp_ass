# QueueEase – Virtual Queue Management Mobile App

## Human–Computer Interaction (HCI) Group Assignment

### Group 5

## Project Title

**QueueEase – Virtual Queue Management Mobile App**

---

## Problem Statement

University students often spend a lot of time waiting in queues at service points such as the Registry, Finance Office, Clinic, and Accommodation Office. These long queues waste time, cause congestion, and may interfere with students' academic activities. QueueEase is designed to provide a virtual queue management system that enables students to join queues remotely, track their position, receive progress updates, and confirm service completion using their smartphones.

---

## Target Users

- Undergraduate Students
- Postgraduate Students
- University Staff

---

## Main Features

- Student Registration and Login
- Select a University Service Point
- Join a Virtual Queue
- View Queue Position
- Receive Queue Progress Updates
- Leave the Queue
- Confirm Service Completion

---

## Project Summary

QueueEase is a mobile application prototype developed using **Balsamiq** as part of the Human–Computer Interaction (HCI) course. The project focuses on improving the waiting experience for university students through a simple, user-friendly, and efficient virtual queuing system. GitHub is used for project collaboration, documentation, version control, and submission.
